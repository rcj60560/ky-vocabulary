# 词汇书对比功能 - 产品需求文档 (PRD)

**版本**: 1.0
**创建日期**: 2026-06-10
**状态**: 草稿

---

## 📌 功能概述

允许用户上传词汇书PDF（包括影印版），提取其中的单词，与历年考研真题词频数据（data.json）进行对比，展示每个单词在真题中的出现次数。

---

## 🎯 目标

| 目标 | 描述 |
|------|------|
| 核心目标 | 帮助用户了解词汇书中的单词在历年真题中的重要性 |
| 用户价值 | 快速识别高频词，优化学习优先级 |
| 技术目标 | 支持影印版PDF（OCR），准确率≥80% |

---

## 👤 用户故事

作为考研考生，我有一个词汇书PDF，我想知道书中每个单词在历年真题中出现了多少次，这样我可以优先学习高频词。

---

## ✨ 功能需求

### 1. PDF上传
- [ ] 支持拖拽上传PDF文件
- [ ] 支持点击选择PDF文件
- [ ] 显示文件大小和名称

### 2. 单词提取
- [ ] 支持标准文本PDF提取
- [ ] 支持影印版PDF（OCR）
- [ ] 过滤停用词（a, an, the等）
- [ ] 去重处理

### 3. 词频对比
- [ ] 查询单词在data.json中的匹配项
- [ ] 返回总出现次数
- [ ] 返回出现过的年份
- [ ] 计算频率排名（X/8122）

### 4. 结果展示
- [ ] 表格形式展示
- [ ] 可排序（按出现次数、字母序）
- [ ] 显示未匹配的单词（真题中未出现）

### 5. 错误处理
- [ ] OCR识别失败提示
- [ ] 文件过大提示（>50MB）
- [ ] 非PDF文件提示

---

## 🚫 非功能性需求

| 需求 | 要求 |
|------|------|
| 性能 | 100页PDF处理时间<60秒 |
| 准确率 | OCR准确率≥80% |
| 用户体验 | 处理时显示进度提示 |
| 可用性 | 在现有Web界面中集成 |

---

## ⚠️ 边界情况

| 场景 | 处理方式 |
|------|----------|
| PDF全是图片（影印版）| 使用OCR |
| PDF是扫描版+文本混合 | 优先文本，OCR补充 |
| 词汇书包含例句 | 提取所有英文单词 |
| 单词有变体（run/ran/running）| 全部转换为小写对比 |
